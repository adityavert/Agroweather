# AgroWeather – Smart Weather & Farming Advisor

AgroWeather is a weather-based web application designed to help farmers and outdoor workers make informed decisions. Built using HTML, CSS, and vanilla JavaScript, it provides real-time weather information, humidity, wind speed, sunrise and sunset timings, and a five-day forecast using the Open-Meteo API.

The website features a Smart Weather Alert System for potential heat, rain, and strong winds, along with a Smart Farming Advisor that provides practical weather-based recommendations. Its Crop Activity Planner displays planting, fertilizing, and harvesting schedules using predefined crop-calendar data.

**Technologies:** HTML, CSS, JavaScript, Open-Meteo API.

**Goal:** Support better agricultural planning and weather awareness.
